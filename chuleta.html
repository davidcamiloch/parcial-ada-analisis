Σi=1n i = n(n+1)/2    Σi=0n−1 i = n(n−1)/2

Σ i² = n(n+1)(2n+1)/6    Σ i³ = (n(n+1)/2)²

5. Logaritmos y Big-O

logb a = logc a / logc b → log9 n = (log3 n)/2; log3 n = log2 n / log2 3 (misma O)
log(ab) = log a + log b; log(a/b) = log a − log b; log ak = k log a
Orden: 1 < log n < log² n < √n < n < n log n < n² < n² log n < n³ < 2ⁿ < n!
O = cota superior (peor caso); Ω = inferior (mejor); Θ = ambas. Término dominante, sin constantes: 3n² + 10n → O(n²). Recurrencia c + T(n/2) → log n; 4T(n/2) + n → n² (desenrollar: 4kT(n/2k) + 2n(2k−1), k = log₂ n).
Escalamiento: t₂ = t₁ · g(n₂)/g(n₁). O(n²): ×4 al duplicar n; O(√n): ×2 al cuadruplicar.

7. Trampas

  • El acceso de la IZQUIERDA también se cobra: v[i] = v[i] + v[j] = 5 (1 acceso izq + 1 igualación + 2 accesos der + 1 suma); copy[i] = array[i] = 3, no 2.
  • .length se cuenta: vale 1 y se paga en CADA evaluación → i < v.length cuesta 2 (no 1); con int n = v.length; antes del for, la condición vuelve a costar 1.
  • Ciclo que no entra: n2 = j+10; while (n2 < j) → 0 vueltas, cuesta 1.
  • Parece log, es constante: i = n²+5; i >= n²; i/=2 → 1 vuelta (n ≥ 3).
  • Base del log: k/=2 → log₂ (el simulacro dice log₃: mismo Big-O).
  • Llamada en ciclo: se multiplica. getUFPS: log₉ n · log₃ n = Θ(log² n) (cota superior con el n inicial).
  • Ciclo oculto: appendToNew copia i elementos → Σi = n(n−1)/2 → O(n²).
  • < vs <=: con <= una vuelta más. i -= 2 desde n−1: ⌈n/2⌉ = ⌊(n−1)/2⌋+1.
  • sqrt: g*g < n hace que g*g == n nunca sea cierto: siempre −1, no hay mejor caso.
  • swapCount no se lee: sin salida anticipada → Θ(n²) siempre.
  • Interno constante (8 vueltas) no cambia el orden. √n domina a log n.
  • Mejor/peor solo si hay if/while sobre DATOS o return anticipado; si no, O = Ω y hay que decirlo.
  • Selección: "min = j" como cota superior: una por comparación.
  • Recursión: izq = 0 con izq*2 no termina; T(m) = c + T(m/2) → log.
